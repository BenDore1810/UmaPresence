# Reporting a security issue

Use **Report a vulnerability** from the repository's Security advisories page if the private reporting form is available. If it is unavailable, ask the maintainer for a private contact method without including technical details or attachments in the request.

Include the UmaPresence version, whether you used Hachimi or Standalone, and a short description of what you observed. Review any attachment locally and remove Windows usernames, paths, account identifiers, game data, and raw diagnostic captures before sharing it.

Check current Windows downloads against the SHA-256 listed in the release assets. The included checksum manifest covers the extracted package.
